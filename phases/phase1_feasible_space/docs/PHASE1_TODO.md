 # Phase 1 遗留问题清单（待后续实验验证）

## P0（必须在 Phase 2/3 实验中验证）

1. 动态安全距离 vs 静态安全距离的最终收益
- 现状：在当前分割与参数下，静态配置在 2.5m / 10m 层面的自由空间占比并不一定更差。
- 待验证：引入巡检点生成与路径规划后，比较任务可达率、路径长度、最小安全裕量、覆盖率等指标。
- 输出物：统一实验表格（dynamic/static）+ 显著性分析。

2. 动态参数合理区间
- 现状：`d0/k_gps/d_ctrl` 已有一组可运行参数，但仍属工程初值。
- 待验证：结合真实飞控定位误差与机体几何约束（M3E 对角线 380.1 mm）做参数回归。
- 输出物：参数-性能曲线和最终推荐参数区间。

## P1（建议完成）

3. 分层可通行空域与任务语义的耦合
- 现状：已有近地/10m/全体积/逐层扫描可视化。
- 待验证：不同设备类型任务在不同高度层的可达性差异。

4. 未分割区域的归类策略
- 现状：未分割高空障碍按 `unsegmented_type` 处理。
- 待验证：补充分割后对结果的敏感度，避免类型混淆。

5. 输出目录长期管理
- 现状：`outputs/` 累积文件较多。
- 建议：后续按阶段拆分目录（见 README 或项目结构建议）。
