# Phase 2 设计说明（写作草稿）

## A. Viewpoint 在本课题中的作用

本课题中的 viewpoint 不等同于通用 CPP 的“路径采样点”：
- 它同时承担“可成像姿态约束”与“可飞行位置约束”。
- 因此输出拆分为两类：
1. `capture`（位置 + 相机姿态 + target）
2. `nav`（仅位置）

## B. FOV 参数说明（Mavic 3E）

当前配置默认使用：
- `hfov_deg=84`
- `vfov_deg=63`

说明：
- `90°/103°` 更接近感知/避障语境，不建议直接作为巡检成像 FOV。
- 巡检点生成与 coverage 更应采用“成像链路”视场。
- 若后续相机模式（分辨率/裁切）变化，可在配置中覆写。

## C. “接近安全边界拍摄”的解释

当前实现采用：
- `standoff = d_eff + boundary_margin`，即视点放在禁飞边界外侧附近。

可解释为：
- 目标是在满足安全边界前提下尽量接近目标，提高有效分辨率。
- `boundary_margin` 提供执行冗余（定位、控制、建模误差）。
- 这不是“越近越好”的无约束最优，而是“安全约束下的近距成像”。

## D. 覆盖率定义建议

推荐“表面采样点可见率”：
- 先做锥体半空间判定。
- 再做射线遮挡判定。
- 满足二者视为 covered。

全站 coverage 可按各设备采样点总数做加权平均。

## E. 低覆盖率的解释策略

低覆盖率可能来自物理可达性与遮挡，不必强行归因于算法失败：
- 细长结构、邻近高风险区、局部夹缝会天然降低 UAV 可覆盖性。
- 可在论文中单列“不可达区域处置策略”（人工/地面平台协同）。
- 不建议直接剔除难覆盖点后再报告主 coverage，除非明确定义可达性掩码。

## F. 单设备路径规划的定位

建议定位为：
- Phase 2 中用于“可执行性验证 + 展示对比”；
- 非全站最优路径。

跨设备总路径最优应在 Phase 3 统一求解（允许跨设备点合并与全局重排）。
